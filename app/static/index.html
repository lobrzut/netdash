Changelog

Skanowanie

Lokalny skan wyłączony na tym hoście — uruchom agenta zdalnego na maszynie z dostępem do LAN (deploy/agent).

Profil skanu Bezpieczny

Na słabym sprzęcie (RPi, stary PC, NAS, N100) zostaw tryb bezpieczny i mniejszy CIDR (/28 zamiast /24).

Jedna sieć na linię lub oddzielone przecinkiem. Obsługiwane maski /24–/22.

Skanowane w trybie domyślnym obok portów webowych
0 = zachowaj offline na stałe (tylko wyszarzone)
Wake / Sleep on LAN
Jeśli ustawione, WoL/SOL idzie przez GPTWOL zamiast lokalnie
Jak skonfigurować Sleep-on-LAN

Przycisk 💤 w NetDash wysyła magiczny pakiet SOL do hosta. Aby uśpienie zadziałało, na każdym komputerze docelowym musi działać agent nasłuchujący na porcie UDP (domyślnie 9).

Oficjalny projekt: sleep-on-lan (SR-G) · GPTWOL

Alternatywnie ustaw URL GPTWOL powyżej — NetDash wyśle WoL/SOL przez bramkę zamiast lokalnie.

Linux

Zainstaluj sleep-on-lan (pip lub Docker). Agent nasłuchuje na UDP i po odebraniu pakietu z odwróconym MAC wykonuje uśpienie. sleep-on-lan

# pip
pip install sleep-on-lan
sol --udp-port 9

# Docker
docker run -d --net=host --restart=always ghcr.io/sr-g/sleep-on-lan sol --udp-port 9

Zapora: zezwól na UDP port 9 (lub inny sol_port z ustawień NetDash).

# Przykład usługi systemd (/etc/systemd/system/sleep-on-lan.service)
[Unit]
Description=Sleep-on-LAN listener
After=network.target

[Service]
ExecStart=/usr/local/bin/sol --udp-port 9
Restart=on-failure

[Install]
WantedBy=multi-user.target

Windows

Użyj portu sleep-on-lan dla Windows, narzędzi Depicus WakeOnLan, własnego skryptu PowerShell nasłuchującego UDP lub innego agenta SOL. Uruchom jako usługę (NSSM lub Harmonogram zadań przy starcie systemu).

# Przykład: sleep-on-lan (jeśli dostępny dla Windows)
pip install sleep-on-lan
sol --udp-port 9

Zapora Windows: reguła przychodząca UDP dla wybranego portu (domyślnie 9).

macOS

Zainstaluj sleep-on-lan lub własny skrypt UDP. Do lokalnego uśpienia służy pmset, ale SOL wymaga stałego nasłuchu sieciowego na hoście.

pip install sleep-on-lan
sol --udp-port 9
# lub: pmset sleepnow  (tylko lokalnie — nie zastępuje agenta SOL)

Ustawienia systemowe → Sieć → Zapora: zezwól na aplikację agenta SOL.

Skrypty instalacji SOL na hoście

Uruchom wybrany skrypt na komputerze docelowym (jako root / administrator). Nasłuchuje na porcie UDP SOL z ustawień NetDash i uśpia host po odebraniu pakietu z odwróconym MAC.

Wymaga uprawnień administratora. Zapora musi zezwalać na UDP z podsieci serwera NetDash. W BIOS włącz Wake-on-LAN (dla przycisku ⚡).

Automatyczne sprawdzanie dostępności
Skan ARP

Wykryj urządzenia w sieci lokalnej (ping + tabela ARP) i przypisz MAC do serwisu.

Urządzenia z WoL

Przypisz MAC do serwisu — edytuj notatki/MAC na karcie serwisu lub poniżej.

Język
Kopia zapasowa

Eksportuj lub przywróć ustawienia dashboardu, serwisy, klucze API (z sekretami) i notatki. Konto logowania nie jest uwzględniane.

Import Homer (YAML)

Wgraj plik config.yml z Homer — NetDash utworzy serwisy (nazwa, URL, ikona, kategoria). Istniejące adresy URL zostaną pominięte.

Pobrać najnowszy obraz Docker i zrestartować NetDash? Strona będzie niedostępna przez kilkanaście sekund.

    Sprawdzam wersję…

    Aktualizacja z portalu wymaga docker.sock na hoście. Na QNAP zaktualizuj obraz ręcznie:

    1. Watchtower (docker-compose.full.yml z obrazem :latest) — automatycznie co 24 h
    2. Container Station → aplikacja NetDash → Pull obrazu ghcr.io/lobrzut/netdash
    3. Po Pull zrestartuj kontener i sprawdź wersję w Ustawienia → O projekcie

    Skanowanie sieci

    Wybierz sieć (CIDR) do skanowania lub wpisz własną. Na słabym NAS użyj mniejszej maski, np. /28.

    Potwierdź skan sieci

    Skan sieci obciąża CPU i sieć (szczególnie bez ping ICMP — skan TCP). Kontynuować? Na słabym sprzęcie użyj mniejszego CIDR (/28) lub skanuj poza godzinami szczytu.
